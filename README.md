# 零基础上手 DeepSeek Harness：从安装到插件交付的全链路实战

## 仓库说明

本仓库为 DeepSeek Harness 专题分享的配套源码与文档，按目录组织如下（与 B 站 / YouTube 合集章节对应）：

| 目录 | 内容概要 |
| --- | --- |
| `01_一键安装与功能演示` | npx 一键安装、页面功能演示、社区插件安装 |
| `02_基础概念与核心架构` | 基础概念、核心架构、运行模式与可观测性概览 |
| `03_源码方式安装` | 源码安装与运行，定制与插件开发相关操作 |
| `04_插件交付4种方式` | `hello-tool` 树外插件；`--patch` 与 4 种正式交付方式 |
| `05_AI编程辅助插件开发` | AI 编程助手协作；插件定制开发与维护示例 |
| `06_可观测链路跟踪` | Trace / Metrics；模型、工具与 Token 的耗时与成本 |
